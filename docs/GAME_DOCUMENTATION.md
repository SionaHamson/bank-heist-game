# The Bank Heist – Crack the Vault

## Project Description

The Bank Heist – Crack the Vault is a puzzle-based
bank security game.

The player must solve three challenges and unlock
the final vault before the 5-minute timer expires.

## Game Flow

1. Start the mission.
2. Search the security room.
3. Find the first digit.
4. Solve the security terminal puzzle.
5. Find the third clue.
6. Enter the final vault code.
7. Unlock the vault before time runs out.

## Challenges

### Challenge 1

Find the hidden clue.

First digit: 4

### Challenge 2

Solve the security terminal sequence.

3 → 6 → 12 → 24 → ?

Answer: 48

Second digit: 8

### Challenge 3

Find the number of CONFIDENTIAL files.

Number of files: 7

Third digit: 7

## Final Vault Code

487
